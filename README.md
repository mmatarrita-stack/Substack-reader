# Substack Reader Intelligence

Lector de newsletters Substack con clasificación automática por categoría, filtros, notas y vista de brief semanal.

## Features
- Feeds RSS de múltiples newsletters en una sola vista
- Clasificación automática de posts por categoría (IA, Negocios, Liderazgo, etc.)
- Relevancia calculada por fecha y categoría
- Notas personales por post
- Override manual de categoría
- Filtros por período, newsletter, relevancia y estado
- Auto-ocultar posts leídos/descartados
- Vistas: Brief, Tarjetas, Tabla

## Deploy
Hosted on Vercel. Push a `main` para actualizar.
